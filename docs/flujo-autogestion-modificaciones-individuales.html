2. Gap Analysis — Clasificación de Movimientos

Cada tipo de modificación se clasifica por su tratamiento para determinar cuáles son automáticas (nominativas), cuáles requieren recálculo tarifario y cuáles necesitan revisión operativa.

MovimientoProducto(s)TratamientoRuta
Cambio de tomador / beneficiario Todos Nominativo Aplicación automática
Cambio de forma de pago Todos Automático Aplicación automática
Modificación de valor asegurado Autos, Hogar Tarifable Recálculo tarifario
Inclusión / exclusión de coberturas Vida, Salud Tarifable Recálculo tarifario
Cambio de deducible Autos, Salud Tarifable Recálculo tarifario
Ampliación fuera de política Todos No estándar Revisión operativa → Reenganche

Nota: la clasificación es una propuesta base para validar con negocio. El Motor de Decisión concentra las reglas; Simón Ventas solo presenta el resultado y captura la solicitud.

3. Definición de Tipos de Tratamiento

Qué significa cada categoría de movimiento y cómo se resuelve.

🟢 Nominativo / Automático

Cambio de datos que no altera la prima ni el riesgo. Se aplica en línea sin intervención humana ni recálculo.

🟡 Tarifable

Movimiento que modifica prima o condiciones. El Motor recalcula, presenta la nueva prima y, con aprobación, se aplica.

🔵 No Estándar

Movimiento fuera de parámetros de suscripción. Genera solicitud para revisión operativa y retoma vía el Módulo de Reenganche.

🔁 Reenganche

Operaciones retoma la solicitud precargada, ajusta deducibles/coberturas y devuelve el caso al Motor para revalidar reglas.
